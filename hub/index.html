Student Project

HUB
A personal interface

Automotive interface design is constantly evolving with new technologies and trends. Looking to the future is especially important in this field, which is why this project focuses on developing innovative UX/UI concepts.

New technologies can also create distractions, so this project aims to make an intuitive, comfortable interface with the features drivers need while supporting safe driving. Because the smartphone plays such an important role in everyday life, HUB reimagines it as a driving interface. Rather than adapting a typical smartphone interface for use behind the wheel, the concept transforms the phone into an interface designed specifically for driving.

02 / A personal connection

Your phone becomes your key.

Many young and new drivers share a car, but still want a driving experience that feels like their own. HUB explores how a smartphone can become a personal key: identifying the driver and bringing their individual settings into the vehicle.

Navigation, media, and other preferences can be set up in advance, making it easier to switch between drivers and helping each person feel at home in the car. The goal is a user-friendly, driving-focused interface that makes essential features accessible while keeping interactions clear and minimizing distraction.

05 / The interface in context

The familiar logic of a car interface.

Rather than treating the phone like a conventional touchscreen, the interface is inspired by a car's analog controls. Functions are grouped into clear sections inspired by familiar dashboard layouts. No menus and sub-menus or finnicky touch controls, just clear directions and predictable movements.
